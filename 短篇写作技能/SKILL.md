# 短篇写作技能（V2.3 — 长篇规则子集提取 + 知识库联动 + 独立运行）

> 本技能为长篇流水线（03a/正文终稿打磨师）的短篇适配版，适用于单篇 8K-35K 字的短篇/中篇创作（35K 封顶，超出不承接）。
> 核心理念：保留长篇流水线中影响产出质量的核心规则，删除跨章管理机制。
> **独立运行**：本技能可不依赖其他任何 skill 独立完成 8K-35K；对正文终稿打磨师/方法论库的引用均为可选增强，缺失时使用技能内嵌规则（反注水 6 条/冰山 5 条/质感 5 技/核心 7 Gate 要点均已内嵌）；两套规则冲突时以内嵌规则为准。
> **V2.1 重大更新**：① 分段执行协议（15K-30K中篇分3-5段+迷你衔接包+段间暂停）；② 自检项从10项增至15项（恢复P1级检查）；③ 审美基准对齐正文终稿打磨师（网文顶级质感，非出版级）；④ 去AI味Gate对齐其核心7 Gate（非全量17）；⑤ 收敛轮数调整为"2轮基础+1轮可选深度"；⑥ 题材适配说明。
> **V2.2 新增**：① 接入 Obsidian 方法论库（知识卡片 plot 系列 + 练习卡 + checklist），三步流程各绑定知识库参考（见"Obsidian 方法论库联动"）；② 读取协议与上游正文终稿打磨师一致：MCP obsidian 优先、直接读文件降级、每场景只读 1-2 张禁全量、库不可读跳过不阻断；③ 卡片用于校准技法/选型参考，不复制卡片内容进正文。
> **V2.3 新增**：① 字数上限 30K→35K，整体按 35K 篇幅设计，35K 以上不承接；② "不是A是B"收紧为全篇≤1次（尽量0次）；③ 新增 Step 1.5 大纲确认闸门（先出大纲确认再写正文，可跳过）；④ 全篇配额改为字数档位表（避免长篇幅配额失真）；⑤ 段间暂停改为"连写2段再停"减少交互；⑥ 新增独立运行声明，不依赖其他 skill 即可完成 8K-35K。

## 适用范围
- 单篇字数：8K-15K字（中短篇，单次完成）/ 15K-35K字（中篇，分段执行）——**35K 封顶，超出不承接**
- 不需要跨章衔接、滚动建纲、伏笔追踪表
- 短篇可自包含完成，中篇分段完成
- 35K 上限面向番茄短故事（官方 6000-80000 字）等长中篇赛道；纯短篇平台（盐言/每天读点故事）建议 8K-20K

## 与长篇流水线的区别

| 维度 | 长篇流水线 | 短篇流水线 |
|------|-----------|-----------|
| 字数 | 100万+字 | 8K-35K字 |
| 步骤 | 7步（含项目初始化） | 3步半 |
| 细纲 | 全书完整细纲（滚动建纲） | 单篇大纲（一次性） |
| 扩写+精修 | 分离(03a→正文终稿打磨师) | 合并为单步 |
| 去AI味 | 17 Gate+三遍法 | 核心7 Gate+两遍法 |
| 自检项数 | 40项(P0+P1+P2) | 15项(P0+精选P1) |
| 收敛轮数 | 3轮 | 2轮基础+1轮可选深度（共3轮上限） |
| 衔接包 | 需要（V5.2 P0/P1分级） | 中篇分段时用迷你衔接包（≤200字，V2.1放宽+伏笔登记） |
| 滚动建纲 | 需要 | 不需要 |
| 跨章去重 | 需要 | 不需要 |
| 伏笔追踪 | 需要 | 轻量（迷你衔接包伏笔登记，人工把控） |
| 频率 | 每章循环 | 单次/分段完成 |
| 审美基准 | 网文顶级质感（正文终稿打磨师） | 网文顶级质感（与正文终稿打磨师对齐） |

## 分段执行协议（V2.1新增）

> **核心问题**：V2.0宣称"单次会话输出完整短篇"，但15K-35K字的中篇在单次会话中难以保证质量（上下文窗口限制+后半段质量递减）。V2.1引入分段执行协议解决此问题。

### 字数分级与执行模式

| 字数范围 | 执行模式 | 段数 | 每段字数 | 衔接包 |
|----------|----------|:----:|:--------:|--------|
| **8K-15K**（中短篇） | 单次完成 | 1段 | 全篇 | 不需要 |
| **15K-35K**（中篇） | 分段执行 | 3-6段 | 5K-7K/段 | 迷你衔接包（含伏笔登记） |

### 中篇分段执行流程

```
【分段执行流程 — 15K-35K中篇】

Step 1: 定位（同短篇，确定全篇结构+字数预算+分段草案）
  └─ 输出：结构+字数预算+分段草案（每段的目标字数+情节范围+核心情绪）

Step 1.5: 大纲确认（V2.3新增）
  ├─ 产出：正式大纲（分段计划表：每段事件+核心情绪+伏笔登记）
  └─ 暂停 → 等待用户确认（继续/调整/重出；用户说"直接写"可跳过）

Step 2: 逐段写作（每段独立执行扩写+精修合并；每连写 2 段暂停一次）
  ├─ 第1段：开头+发展前半 → 生成迷你衔接包（含伏笔登记）
  ├─ 第2段：发展后半+高潮前奏 → 读取上段衔接包 → 生成迷你衔接包
  │   └─ 连写 2 段后 → 暂停 → 等待用户确认
  ├─ 第3段：高潮+收尾 → 读取衔接包
  └─ （3-6段按分段计划表执行；4-6段时均分各段职责，暂停节奏见段间暂停协议）

Step 2.5: 自检Gate（V2.1 新增 — 写作与去AI味之间的轻量级质检）
  └─ 段级轻检 3 项（字数/AI味基线/冲突）+ 全篇终检 5 项 → 通过则进入Step 3，未通过则回退修正
     ① 字数：短篇8K-15K / 中篇每段5K-7K（全局硬约束）
     ② 对话比：≤60%（全局硬约束；分段时按整篇合并计算）
     ③ AI味基线：无A级禁用词（"意味着/这说明/他发现/显然"等，全表见正文终稿打磨师 Gate 1），"不是A是B"≤1次/全篇（尽量0次）
     ④ 情绪锚点：至少1个物理锚点+1个情绪转折点（情绪词三级分级制：L1场景0个/L2≤1个/L3≤2个每千字）
     ⑤ 冲突完整性：每段至少1个核心冲突，无"读完什么都没发生"的段落

Step 3: 去AI味（全文统一执行，非分段执行）
  └─ 核心7 Gate（G1/G2/G3/G6/G9/G10/G11）+ 两遍法 → 收敛终止协议
```

### 迷你衔接包格式（V2.1新增）

> 段间衔接使用迷你衔接包，不使用长篇的V5.2 P0/P1分级衔接包。迷你衔接包极简设计，确保段间连贯即可。
> V2.1: 迷你衔接包从100字放宽到200字，改为必填字段+可选字段结构。

```
【迷你衔接包 — 段间衔接】（限200字以内，V2.1放宽）

【必填字段】
角色状态：{主角当前位置/身体状态/心理状态}
当前目标：{主角此刻想做什么}
未解悬念：{尚待揭示的1-2个关键悬念}

【可选字段】
段尾锚点：{最后一个场景的物理细节，供下段开头呼应}
情绪基调：{本段结尾的情绪状态，供下段开头承接}
伏笔登记：{本段埋下/回收的伏笔 1-2 条（15K-35K 建议填写，防跨段丢失）}
```

**示例**：
```
角色状态：沈夜在县衙偏房，左肩被画皮怪抓伤（轻伤），情绪从恐惧转为愤怒
当前目标：查清画皮怪的来历，找到柳如烟
未解悬念：铜钱为什么对画皮怪有反应？柳如烟去了哪里？
段尾锚点：桌上铜钱微微发烫，裂纹中渗出一丝血色
伏笔登记：铜钱对画皮怪有反应（埋下，待第3段揭示）；柳如烟去向（埋下）
```

### 段间暂停协议（V2.3：连写2段再停，减少交互）

- 15K-35K 中篇默认**每连写 2 段暂停一次**（全篇最多暂停 3 次），确认后再继续——减少往返、保留质量闸门
- 用户可随时要求：恢复"每段必停" / 改为"全部写完再确认"
- 暂停时输出：本段字数 | 迷你衔接包 | 下段计划（预计字数+情节范围）
- 用户可指示：继续 / 调整方向 / 修改本段
- 此机制确保中篇质量不因单次会话过长而递减

### 与03a及正文终稿打磨师的兼容性说明

> 短篇/中篇的分段执行**不使用03a扩写与内置质检分离的流程**。短篇流水线是长篇流水线的精简子集，扩写+精修合并为单步执行。分段执行中的"段"不等于长篇的"章"——段是输出管理单位，不涉及02a细纲、02b质检、衔接包链等长篇机制。迷你衔接包是段间连贯性保障，不是02a生产的V5.2衔接包。

## 三步半流程（定位→大纲确认→写作→自检→去AI味）

### Step 1：定位（5分钟）

**核心问题**：这篇短篇的"一句话卖点"是什么？

```
【短篇定位模板】

1. 类型标签：悬疑/言情/都市/奇幻/恐怖/现实
2. 一句话梗概：[主角]在[情境]下，做了[某事]，导致[结果]
3. 情感目标：让读者感到[爽/虐/怕/甜/思]
4. 对标风格：[如：类似知乎盐言《XXX》的叙事风格]
5. 目标字数：8K-15K字（中短篇）/ 15K-35K字（中篇）

6. 核心设定（如有特殊世界观）：
   ├─ 规则1：
   ├─ 规则2：
   └─ 规则3：

7. 角色表（1主角+2-3重要配角）：
   ├─ 主角：[姓名][身份][性格核心]
   ├─ 配角1：[姓名][功能]
   └─ 配角2：[姓名][功能]
```

**定位补充（V2.0新增）**：

- **核心情绪定位**：这篇短篇要让读者读完后的核心感受是什么？
- **爆点定位**：短篇只需要1-2个爆点，确定位置
- **字数预算分配**：开头(15%)→发展(50%)→高潮(25%)→收尾(10%)
- **分段计划（中篇专用，V2.1新增）**：如目标字数>15K，确定分段数+每段情节范围
- **知识库参考（V2.2新增，可选）**：选题定类型可查知识卡片 plot 系列（`方法论库/经典情节20种/plotNN_*.md`，按 one_liner/three_act 匹配情节类型）与 `规则与清单/checklist_情节类型适配.md`

**标点规范**：全篇（省略号≤5/破折号≤4/感叹号≤15）

#### 题材适配说明（V2.1新增）

> 短篇也可选择题材方向，不同题材影响质感技法的侧重。

| 题材方向 | 质感侧重 | 必用技法 | 可跳过技法 |
|----------|----------|----------|-----------|
| 悬疑/推理 | 冷峻氛围+信息差控制 | 冰山原则、感官精准投放 | 脏感注入 |
| 言情/甜宠 | 情感细腻+身体语言 | 对话人味、动作链写生理状态 | — |
| 都市/现实 | 生活质感+烟火气 | 脏感注入、具体名词替代形容词 | 设定藏在生活里 |
| 奇幻/玄幻 | 世界观沉浸+力量感 | 设定藏在生活里、感官精准投放 | 脏感注入 |
| 恐怖/惊悚 | 恐惧递进+感官压迫 | 感官精准投放（多维叠加）、冰山原则 | 对话人味（对话少） |

> 题材适配优先于通用技法：题材表标注"可跳过"的技法在该题材下不强制（如悬疑可跳脏感注入）；与正文终稿打磨师通用技法冲突时以题材表为准。

### Step 1.5：大纲确认闸门（V2.3新增 — 先确认蓝图再动笔）

> 定位完成后，先产出大纲并暂停确认，确认后才进入 Step 2 写作。用户可指示"直接写"跳过本闸门。

**大纲形态按字数分级**：

| 字数档 | 大纲形态 | 确认方式 |
|---|---|---|
| 8K-15K | **轻量大纲**：事件序列 ≤300 字（起承转合各列 1-3 个关键事件+冲突） | 快速确认，可跳过 |
| 15K-35K | **正式大纲**：分段计划表（每段目标字数 + 情节范围 + 核心情绪 + 伏笔登记） | 确认，可要求调整 |

**确认交互**：
- 输出大纲后暂停，用户可指示：**继续 / 调整某段 / 重出大纲**
- 用户说"直接写"可跳过确认（8K-15K 建议快速确认，15K-35K 建议保留确认）
- 大纲写作本身防 AI 味：用"事件+冲突+情绪"表述，不写说明文、不做升华总结
- 大纲产出后即作为 Step 2 的分段计划依据（与分段执行协议无缝衔接）

### Step 2：写作（核心执行）

合并03扩写+精修为单步执行，保留以下长篇核心规则。

**执行原则**：
1. 单次/分段完成：中短篇一次性生成，中篇分段生成
2. 自带精修：写作时直接应用长篇流水线中正文终稿打磨师的技法（潜台词/留白/金句；技法要点见 2.4 质感注入/2.5 冰山原则内嵌规则，独立运行时按内嵌要点执行）
3. 字数控制：8K-35K字，单篇自包含
4. 起承转合：开头钩子 → 冲突升级 → 高潮反转 → 余韵收尾

**结构模板**：

```
├─ 开头（15%）：钩子+角色+场景
│   ├─ 第1句：必须抓住读者
│   ├─ 前200字：建立冲突或悬念
│   └─ 前500字：角色出现+核心问题提出
│
├─ 发展（50%）：冲突升级+信息释放
│   ├─ 3-5个情节推进点
│   ├─ 过程中逐步释放背景信息
│   ├─ 穿插小高潮/小反转
│   └─ 配角互动增加层次
│
├─ 高潮（25%）：核心冲突解决
│   ├─ 最大的反转/揭示/对抗
│   ├─ 所有伏笔回收
│   └─ 情绪达到顶点
│
└─ 收尾（10%）：余韵+收尾
    ├─ 情感释放或留白
    ├─ 呼应开头
    └─ 留给读者回味空间
```

**短篇字数控制**：
- 按结构分段生成，每段完成后检查字数
- 若总字数<8K：在"发展"段补充冲突层次
- 若目标字数>15K：自动转入中篇分段模式（3-6段，每段5K-7K）
- 若目标字数>35K：超出适用范围，不承接（建议拆分为多部或另行评估）

#### 2.1 审美基准对齐正文终稿打磨师（V2.1更新）

> **V2.1关键调整**：审美基准从"出版级质感"调整为"网文顶级质感"，与正文终稿打磨师完全一致。
> 对标对象：猫腻（文人气韵）/烽火戏诸侯（江湖质感）/愤怒的香蕉（细腻日常）/烟雨江南（冷峻氛围）。
> 底层逻辑：沉浸式画面感视角，非客观摄影机视角。

#### 2.2 反注水最高铁律（6条全保留）
1. 禁止循环式排查（多个相似物品挨个描写超过1次）
2. 禁止无意义物理触碰反馈（普通物品的触感/磨损声/笔帽咔哒声）
3. 禁止滥用感官比喻（日常场景用"像从地底深处"等）
4. 禁止心理活动套娃（"他原本预期...但他发现..."）
5. 禁止潜台词解释（"他发现/这说明/这意味着"）
6. 禁止弱智明喻（用"像/仿佛"强行渲染氛围，全篇超过2处）

#### 2.3 否定排比三连零容忍
- "没有…没有…没有…" / "不是…不是…不是…" → 立即删除
- 否定排比+升华句（"而是…/只有…/那是一种…"）→ 立即删除整段
- 全篇容忍度：0次（对话中可保留）
- **短篇专用标准**：全篇否定翻转（"不是A是B"）≤1次（尽量0次，严于上游长篇每章≤2次）

#### 2.4 质感注入五大技法（全保留）
1. 动作链写生理状态：3-4个连续动作传达角色状态（非微动作白噪音）
2. 具体名词替代形容词："桌上放着半壶凉透的茶"而非"桌上放着茶具"
3. 设定藏在生活里：世界观通过日常场景释放，非说明文
4. 感官精准投放：日常极简白描 / 关键异常点多维叠加（二分法）
5. 对话人味：口癖/跑题/言不由衷/信息差

#### 2.5 冰山原则五大铁律（全保留）
1. 只写水面上的1/8，让读者感受到水面下的7/8
2. 角色的过去通过"碎片+矛盾"释放，非履历表
3. 情绪不直说，用物理锚点承载（"他攥着那张纸，指节发白"）
4. 关键信息通过"角色反应"暗示，非叙述者解释
5. 留白比填满更有力量——读者脑补的永远比写出来的好

#### 2.6 "不是A是B"句式限流
- 全篇≤1次（尽量0次；严于上游长篇每章≤2次）
- 超出 = 改用直接陈述/动作描写

#### 2.7 常识性错误零容忍
- 物理/材料/生理/空间/时间/因果常识检查
- 超自然行为必须有设定依据

**短篇精修规则子集说明**：
- 必用技法：感官入口重定向、潜台词对话法、内心矛盾外化法（这3项是短篇质感的核心；独立运行时按内嵌要点执行——感官入口重定向=核心场景非视觉入口优先、潜台词对话法=对话言外之意/答非所问、内心矛盾外化法=言行不一外化）
- 选技法：脏感注入（仅现实题材）、感官锚点深度穿插（仅关键场景）
- 跳过技法：叙述厚度保障中的"对话与叙述黄金比例"机制（短篇不做比例配置，但对话占比硬上限 ≤60% 仍生效）、模块R情感收束（短篇高潮集中，不需要长线收束）
- **知识库参考（V2.2新增，可选）**：按场景查练习卡（`方法论库/开始写吧/exNNN_*.md`）校准技法——对话生硬→ex050 无言的对话 / ex053 对话的等级；感官与描写空泛→ex018 五种感觉 / ex068 最难忘的食物；卡文枯竭→ex021 克服枯竭期；句子节奏与隐喻→ex067 长句子 / ex083 通过隐喻产生意义；视角与心理距离→ex030 第三人称叙述和心理距离
