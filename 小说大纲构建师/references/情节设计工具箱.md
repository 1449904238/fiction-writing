# 情节设计工具箱

## 故事引擎速查

以 `目标 -> 阻力 -> 选择 -> 代价 -> 状态变化 -> 新问题` 作为最小叙事循环。每一次升级至少改变其中一个条件，避免以更强敌人或更大数字重复前一卷。

主角弧不写“变得成熟/强大”。写成：错误信念在什么压力下失效，主角为维护它付出什么代价，最后用什么相反行动证明变化。

对手必须主动行动。每次主角解决一个问题，对手要改变资源配置、规则、联盟、信息或攻击目标，不能只等待主角登场。

## 场景、钩子与反转

核心场景使用 GOCS：目标具体到当场可完成或失败；障碍有行动者；选择排除无代价的两全；状态变化能被下一场引用。

钩子优先来自未完成的代价、被迫选择、关系变化、证据缺口或新行动，不靠省略关键事实。低压章可以用“兑现理由”取代高刺激钩子。

反转前至少布置两类可回溯依据：行为/物件证据与动机/规则证据。反转后写角色如何误判、付出什么、改选什么；没有后果的反转只是信息噪声。

## 题材调整

| 题材重心 | 优先升级 | 常见错误 |
|---|---|---|
| 悬疑 | 证据、嫌疑人模型、认知与风险 | 为保谜底而隐藏读者本应知道的事实 |
| 言情 | 边界、信任交换、共同目标与失去风险 | 用误会拖延关系而没有真实价值冲突 |
| 成长/战斗 | 能力边界、资源、战术和代价 | 用数值膨胀取代新问题 |
| 职场/现实 | 准入、制度、利益和声誉 | 把专业规则当装饰背景 |
| 历史/架空 | 制度、资源、地理和身份限制 | 现代价值观无代价地碾压环境 |

## 审美检查

- 能否删掉一个事件而不影响选择或状态？能则删、合并或重写。
- 把主角换成另一个人，选择还会一样吗？会则人物不够具体。
- 对手不行动故事仍能推进吗？能则冲突引擎不足。
- 卷末只换地图、敌人或称号吗？是则没有真正升级。
- 反转是否让读者重新理解已知内容并改变后续选择？否则不算反转。
