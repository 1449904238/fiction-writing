# 扫榜与选书指南（Step 1 执行时按需读取）

> 目标：找到值得拆的对标书。核心原则——**扫榜看模式，不看排名**：单本上榜只是线索，跨样本重复模式才算信号。

---

## 1. 各平台榜单与数据可得性（2026-08 快照，随时间需更新）

| 平台 | 推荐看的榜 | 公开可得信号 | 抓取现实 |
|------|-----------|-------------|---------|
| 番茄 | 男频/女频品类榜（都市/玄幻/现言/古言等，每品类连载前100） | 榜单排名、阅读人数 | 网页版存在反爬与验证码，浏览器半自动成功率存疑，S2 失败尽快降 S3 |
| 起点 | 月票榜、新书榜、三江推荐 | 月票数、荣誉标识（万人追捧/首订过万等）、收藏 | 有验证码拦截风险 |
| 晋江 | 金榜、千字金榜、新书榜 | 收藏数、积分 | 需 Cookie，请求过快会被限流 |
| 七猫 | 热门榜 | 阅读量（口径待核实） | 未验证 |
| 第三方聚合 | 网文大数据类站点（wangwendashuju.com 等） | 多平台榜单快照聚合 | 可作为 S2/S3 的优先替代数据源 |

> **数据现实**：追读率、完读率（番茄口径为"X万字读完率"）、均订、首订均为**作品作者后台私有数据**，拆别人的书时不可得——不要把市场分析建立在拿不到的指标上。

## 2. 免费平台 vs 付费平台的看榜逻辑

- **番茄/七猫（免费+广告）**：核心看留存与读完——榜单按品类连载书加权计算，新书爆发速度比绝对排名更有信息量
- **起点（付费订阅）**：核心看订阅与月票——荣誉标识是经过验证的硬信号（万人追捧/首订过万）
- **晋江（女频付费）**：核心看收藏与千字金榜——收藏增长快的新文比金榜常客更值得新人参考

## 3. 扫榜两大陷阱（行业共识）

1. **幸存者偏差**：榜上有名 ≠ 跟风能复制。跟大神写同题材，读者大概率只认原作者。→ 用选书五问过滤（SKILL.md Step 1.2）
2. **榜单滞后性**：畅销榜多是老书长期积累的结果，反映的是过去；新书榜/新书期爆发才反映当前风向。→ 优先新书榜，畅销榜只看品类大盘

## 4. 数据快照纪律

所有扫榜产出（选题决策.md / 拆文报告市场维度）必须记录：
- 采集日期 + 数据来源 + 置信度（高=实时榜单 / 中=近期转载 / 低=可能过时）
- 市场维度结论有效期约 6 个月（题材风向变化），超期建议重扫；文本/结构维度结论长期有效

## 5. 选题决策.md 输出结构

```
## 选题决策
### 数据快照
- 采集日期 / 来源 / 置信度
### 榜单观察
- 反复上榜的题材（跨样本信号）
- 新兴题材 / 衰退题材
### 推荐方向（1-2 个）
- 热度 + 竞争密度 + 与用户优势的匹配
- 推荐拆解书目（选书五问逐问回答）
### 风险提示
### 最终建议
```
