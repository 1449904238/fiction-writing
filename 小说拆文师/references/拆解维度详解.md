# 拆解维度详解（Step 4 执行前必读）

> 本文件是三维度拆解的完整执行清单。SKILL.md 定义流程与纪律，本文件定义"具体看什么、怎么判"。

---

## §1 市场维度

### 1.1 一句话卖点（转述测试）

- 模拟读者向朋友推荐："你知道吗，有本书讲的是……"
- 提炼公式：`[身份] + [金手指/设定] + [核心爽点]`
- 判断标准：一句话说不清 = 卖点模糊；一句话说完对方想追 = 优

### 1.2 书名与简介拆解（包装层，D2 起即可拆）

- 书名：是否含品类热词？搜索友好吗？能暗示核心爽点吗？（热词举例：重生/满级/开局/退婚/马甲/规则怪谈）
- 简介：第一句是否直给核心冲突/金手指？有没有钩子前置（悬念句结尾）？
- 标签：平台分类标签的选择透露的目标读者

### 1.3 读者画像

- 年龄层 / 阅读场景（通勤/睡前/摸鱼）/ 核心需求（爽/甜/虐/悬疑/新奇）/ 情绪代偿（现实缺什么，小说给什么）

### 1.4 平台适配（经验口径，随市场变化需更新）

| 平台 | 节奏特征 | 核心指标（公开可得） | 私有数据（拆别人的书拿不到） |
|------|---------|--------------------|------------------------|
| 番茄 | 快节奏、前500字进主题、单章约2000字上下（1500-2500，经验值） | 品类榜排名、阅读人数 | 追读率、"X万字读完率"（仅作者后台） |
| 起点 | 慢热可容忍、世界观构建、长线伏笔 | 月票数、荣誉标识（万人追捧/首订过万等） | 均订/首订（仅作者后台） |
| 晋江 | 情感线主导、文笔权重高 | 收藏数、金榜/千字金榜 | 千字收益（入V后） |

> **市场维度数据纪律**：指标只用公开信号（榜单排名/月票/收藏/阅读人数/评论关键词）。追读率、完读率、均订等是**他人作品的私有后台数据**，仅当有作者经验帖披露时参考，并标注来源与"孤例"属性。

### 1.5 读者评论分析（高性价比公开数据源）

- 采集位置：书评区 / 平台评论区 / 贴吧 / 豆瓣小组
- 差评集中在哪几章 → 节奏崩坏点定位（配合 D1+ 原文验证）
- 好评高频词 → 真实卖点验证（与 1.1 提炼的卖点对照，读者说的才算数）
- 弃书讨论 → 结构红线（什么情节赶走了读者）

### 1.6 评分锚点（市场维度 1-10）

| 分段 | 锚定特征 |
|------|---------|
| 9-10 | 转述测试一句话流畅且对方想追；评论高频词与提炼卖点完全吻合；包装（书名/简介）精准命中品类热词 |
| 7-8 | 卖点清晰可一句话复述；评论印证主要卖点 |
| 5-6 | 卖点存在但表述绕；评论焦点分散 |
| ≤4 | 一句话说不清这本书讲什么；书名简介与内容错位 |

## §2 文本维度

### 2.1 开篇分析（黄金三章硬标准，行业共识口径）

| 位置 | 检查点 |
|------|--------|
| 前 300 字 | 核心冲突/困境是否出现？（危机切入/日常异常/对话开场/结果前置均算，纯背景介绍不算） |
| 前 500 字 | 金手指/核心设定是否亮相或强暗示？ |
| 前 1000 字 | 第一个小爽点/小反转是否落地？ |
| 第 1 章末 | 钩子是什么类型？强度如何？ |
| 第 2 章 | 铺垫还是释放？主角是否开始用金手指应对冲突？ |
| 第 3 章 | 短期目标是否确立？读者"入坑"理由是否成立？ |

### 2.2 金手指拆解（D0/D1 必拆项）

- 亮相位置：第几章第几百字？方式（直接展示/危机中觉醒/他人视角揭示）？
- 一句话复述测试：金手指能否一句话讲清？（讲不清 = 传播成本高）
- 绑定强度：与主线冲突是否强绑定？（可剥离的装饰性金手指 = 弱设计）
- 成长阶梯：有没有清晰的升级路径与天花板设计？

### 2.3 章末钩子四分类

| 类型 | 特征 | 示例形态 |
|------|------|---------|
| 危机钩 | 下一刻有明确危险 | 敌人到场/陷阱触发/倒计时开始 |
| 悬念钩 | 抛出未解之谜 | 异常现象/关键人物说了一半的话 |
| 信息差钩 | 读者知道、角色不知道（或反之） | 身份即将揭穿/读者先看到埋伏 |
| 情绪钩 | 情感张力悬置 | 误会刚起/告白被打断/背叛揭晓前一刻 |

统计：钩子覆盖率 = 有钩章节数 / 总章数（以实际拆解章节为窗口，上限前 30 章）。

### 2.4 句式与节奏

- 平均句长、短句占比（用 text_stats.py，勿目测）
- 段落长度：短段密集（手机阅读友好）还是长段叙事？
- 对话占比：对话行占比 50-65% 为网文常见优区间（番茄经验值约 60/30/10：对话/旁白/心理）
- 叙述者距离：贴身（跟主角视角）/中距/全知

### 2.5 感官与描写

- 最常用感官（视/听/触/嗅）与密度（每多少字一处——需抽样统计）
- 是否有物理代价描写（受伤/疲惫/环境脏感 → 真实感来源）

### 2.6 对话风格

- 口语化程度：说书人腔（高）还是文人腔（低）？
- 说话方式：直给 or 话里有话（潜台词密度）？
- 对话承担多少设定交代？（用对话灌设定 = 弱；用冲突带出设定 = 强）

### 2.7 评分锚点（文本维度 1-10）

| 分段 | 锚定特征 |
|------|---------|
| 9-10 | 钩子覆盖率≈100%；对话占比 50-65%；每 500-800 字一处情绪波动；开篇三硬标全过；感官有辨识度 |
| 7-8 | 钩子覆盖≥80%；开篇至少两项硬标过；爽点间隔≤3 章 |
| 5-6 | 钩子覆盖≥60%；偶有连续 2 章平推；开篇只过一项硬标 |
| ≤4 | 连续 3 章无钩子/大段设定堆砌/开篇纯背景铺垫 |

> 以上数字为行业作者经验口径（非平台官方标准），作评分锚点用，不作用稿承诺。

## §3 结构维度

### 3.1 剧情段拆解（结构分析的基本单元）

每个剧情段一行记录：

```
| 段号 | 起止章 | 核心冲突 | 主角变化 | 结尾钩 | 情绪功能 |
```

情绪功能四分法：**铺垫**（埋冲突/埋信息）→ **蓄力**（压力累积/期待拉高）→ **爆发**（爽点兑现/危机落地）→ **余波**（情绪消化/关系变化/下一钩）。

### 3.2 呼吸节奏

- 铺垫段 vs 爆发段的比例
- 爽点间隔：多少章一个小爽（行业经验：3 章一小爽、10 章一大爽）
- 情感线拉扯节奏（女频重点）：甜→虐→甜的循环周期
- 大高潮前是否有小高潮递进铺垫

### 3.3 伏笔系统

- 伏笔登记表：`| 伏笔内容 | 埋设章 | 回收章 | 间隔 | 类型（物件/对话/事件/设定/角色） |`
- 埋收健康度：前 30 章埋了多少？已回收多少？有无超长线伏笔（跨卷）？
- 连环坑：旧伏笔未收又开新坑的位置（过密 = 读者信任透支）
- 窗口纪律：**拆解窗口内未回收 ≠ 不回收**——仅"埋设后约 30 章仍无回收且持续开新坑"计连环坑；窗口外的回收状态标注"窗口外不可判"，不参与结构评分扣分

### 3.4 角色功能位映射

**男频模板**：
- 对手位：提供压迫感 + 打脸对象（要有压迫感 + 表演型人格才立得住）
- 盟友位：情感羁绊 + 信息释放
- 催化剂位：推动主角变化 + 制造转折
- 信息位：设定/世界观/伏笔的释放口（导师型，中后期安排退场）
- 三人成戏：主角+同伴+敌人 = 三角张力

**女频模板**（在上述基础上调整侧重）：
- CP位：拉扯感来源（误会/地位差/身份冲突）
- 对照组：衬托主角的平行人物（对照组过得越差，主角选择越被验证）
- 情感障碍位：持续制造 CP 阻力的角色/事件/规则
- 嗑点供给位：高频输出 CP 互动名场面的配置

**原则**：学"功能"不学"人设"——映射时只填功能与素材方向，不复制人设细节。

### 3.5 信息释放节奏

- 设定信息是集中灌输还是分散释放？（每章新设定信息量 ≤ 1 个核心点为优）
- 关键信息用什么载体释放：对话/事件/回忆/他人视角？

### 3.6 评分锚点（结构维度 1-10）

| 分段 | 锚定特征 |
|------|---------|
| 9-10 | 爽点间隔≤3 章且分布均匀；伏笔有埋有收无连环坑；功能位齐全且各有高光 |
| 7-8 | 爽点间隔≤5 章；主要伏笔均回收；偶有一个功能位工具人化 |
| 5-6 | 节奏有明显拖沓段（连续 3-4 章平推）；部分伏笔悬空 |
| ≤4 | 连续 5 章以上无推进；伏笔大面积不回收；功能位缺失或全员工具人 |

## §4 频道分流速查

| 拆解项 | 男频侧重 | 女频侧重 |
|--------|---------|---------|
| 核心引擎 | 升级/打脸/翻盘 | 拉扯/嗑点/情感代偿 |
| 金手指 | 必拆（绑定+阶梯） | 视题材（金手指常弱化为身份/天赋） |
| 功能位 | 对手位权重最高 | CP位+情感障碍位权重最高 |
| 节奏基准 | 3章一小爽·10章一大爽 | 甜虐循环周期+每卷至少一次大嗑点 |
| 钩子侧重 | 危机钩/信息差钩 | 情绪钩/悬念钩 |
| 弃书红线 | 连续无爽点 | CP 长期无进展/强行误会 |

## §5 手法标注词表（片段库专用，从中选词，不自造）

**对白类**：话里有话 / 延迟揭示 / 身份反差 / 嘴硬心软 / 一句破防 / 潜台词留白 / 语气递进
**叙述类**：白描 / 通感 / 精确动词 / 长短句交替 / 留白 / 闲笔衬主线 / 节奏突变（短句连发）/ 拟声造临场感
**结构类**：延迟满足 / 信息差 / 预期违背 / 反转前置铺垫 / 双线交汇 / 余波收束 / 钩子悬置
**情绪类**：反差萌 / 情绪压到最低再释放 / 糖刀交替 / 克制式煽情（不写哭字让读者哭）
