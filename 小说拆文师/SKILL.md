# 小说拆文师 V7.0.1

> 独立拆文工具。核心使命：把一本对标作品拆成**可复用的写作资产**——拆解报告（它为什么好）+ 精彩片段库（好在哪的原句）+ 可复用清单（你能怎么用）。

---

## 使用前提（先读）

| 条目 | 说明 |
|------|------|
| 触发场景 | 用户说"拆这本书 / 拆解爆款 / 分析写作手法 / 提取金句桥段 / 找对标书 / 扫榜" |
| 输入 | 对标书原文（最佳）或简介+评论或仅书名——输入决定拆解深度，见 Step 2 |
| 产出位置 | 项目目录下 `拆文库/{书名}/`（无项目目录时在当前目录创建） |
| 参考文件 | `references/拆解维度详解.md`（Step 4 前**必读**）、`references/输出模板.md`（写产出前必读）、`references/扫榜与选书指南.md`（Step 1 时按需读取） |
| 合规边界 | 拆解原文仅限**个人学习分析**用途，不得公开传播原文或对外二次分发拆文库中的逐字摘录 |

---

## 主流程总览

```
用户来意
  ├─ 已有对标书 → Step 2（数据分级）
  └─ 没有书，想找 → Step 1（扫榜选书）→ 拿到书后 → Step 2
                                    ↓
Step 2 数据分级 D0-D3 → 决定拆解深度（防"数据不足强行拆"）
                                    ↓
Step 3 拆解准备（确认频道/范围/快照信息）
                                    ↓
Step 4 三维度拆解（市场/文本/结构，证据 Gate 全程生效）
                                    ↓
Step 5 精彩片段库提取（金句/桥段/名场面，原文摘录+手法标注）
                                    ↓
Step 6 综合报告 + 可复用清单 + 质量自检
                                    ↓
（拆 ≥2 本时）Step 7 横向对比报告
```

## Step 1：扫榜选书（仅当用户没有锁定书目时执行）

> 详细平台榜单、指标可得性、反爬现实见 `references/扫榜与选书指南.md`。本步骤只做三件事：拿数据 → 选书 → 交付选书结论。

### 1.1 数据获取降级链（S1→S3）

| 级别 | 方式 | 说明 |
|------|------|------|
| **S1 手动输入（优先）** | 用户提供榜单截图/复制文本 | 展示输入模板（见 references/扫榜与选书指南.md 附录）；填完直接进 1.2 |
| **S2 浏览器半自动** | 使用当前会话可用的浏览器自动化能力抓取公开榜单页 | 用户确认后执行；遇验证码/反爬立即停止并降级 S3 |
| **S3 WebSearch 兜底** | 搜索"番茄小说热榜""起点月票榜"等 | 结果多为转载，置信度标"低"；明确提醒用户"建议手动核实最新榜单" |

**降级触发**：用户无数据→S2；浏览器超时/403/验证码/解析为空→S3。任何一级成功即停，不重复采集。

### 1.2 选书五问（核心判据，防"拆错书"）

对候选书逐一过筛，**任何一问不过即降级为备选**：

1. **同频道同流派吗？**——跨频道拆书水土不服，节奏与爽点逻辑不同
2. **是近 6-12 个月火起来的新书，还是老书积累？**——畅销榜多老书，滞后于当前风向；优先看新书榜/新书期爆发
3. **作者是新人还是大神？**——优先拆"新人作者刚火的第一本书"：其成功路径是纯内容驱动、可复制；大神神作依赖名气与读者惯性，新人学不来
4. **成绩是爆发型还是缓慢积累型？**——爆发型 = 内容里有市场验证的钩子，值得拆
5. **你与作者的写作能力差距可跨越吗？**——差距过大则只学结构，不学文笔

### 1.3 产出

`拆文库/选题决策.md`，结构见 `references/扫榜与选书指南.md` §5。

## Step 2：数据分级 D0-D3（拆解深度的硬约束）

> 拆文质量的上限由数据决定。数据不足时**降低深度并明确告知用户**，绝不强行拆出空泛内容。

| 级别 | 数据形态 | 可执行拆解 | 产出预期 |
|------|---------|-----------|---------|
| **D0 完整正文**（≥10 章，越多越好） | 用户粘贴/提供文件路径 | 全部：三维度 + 片段库 + 横向对比 | 高精度 |
| **D1 关键章节**（前3章+高潮章+结尾，5-8 章） | 用户粘贴 | 市场推测 + 黄金三章精拆 + 结构推断 + 片段库（仅限所给章节） | 中高精度，呼吸节奏/长线伏笔标注"推测" |
| **D2 简介+标签+评论** | 用户提供 / WebSearch 补充 | **仅市场维度** + 评论关键词分析 | 市场定位报告；**禁止产出文本/结构维度结论** |
| **D3 仅书名** | WebSearch 公开信息 | **仅市场定位粗判** | 选题参考；**这不是拆文** |

**执行规则**：
- 判定级别后，**第一句话告知用户**："当前数据为 Dx，可执行 XX，不能执行 XX。建议补充前 3 章原文升级到 D1。"
- D2/D3 下用户坚持要"文本分析"时，明确拒绝并解释：没有原文的分析是编造。
- **D 级限制是硬约束，优先级高于证据 Gate**：D2/D3 禁止产出文本/结构维度结论，即使全部标注【推测】也不允许。
- D3 判定后可 WebSearch 补数据：找到简介 + ≥3 条读者评论摘录 → 告知用户并升级按 D2 执行（置信度标低）。
- 用户无法升级数据 → 建议跳过拆文，改做选题参考。

## Step 3：拆解准备

执行 Step 4 前依次确认（缺一项就问用户，不要自行假设）：

1. **频道**：男频 / 女频 / 无CP？——决定用哪套功能位与情绪引擎模板（见 references/拆解维度详解.md §4）。用户无法确认时按题材默认推断，报告标注【频道推断】
2. **拆解范围**：以用户实际提供的章节为准（提供量大时建议：前 30 章必拆 + 高潮章 + 抽样中段 3-5 章；数百章不逐章全拆，按"剧情段"切分，见 Step 4.3）
3. **快照信息**：在 `拆文报告.md` 头部记录——拆解日期、数据级别 Dx、拆解章节范围、原文来源、数据置信度（高/中/低）
4. **原文落盘**：用户粘贴的原文存入 `拆文库/{书名}/原文/第NNN章_章名.md`，作为后续证据引用的唯一来源
5. **窗口意识**：拆解窗口外的结论（长线伏笔回收、分卷级节奏、"10章一大爽"等）一律标注"窗口外不可判"，不参与评分扣分——窗口内看不到的不算书的缺陷

## Step 4：三维度拆解（核心）

> 执行前**必读** `references/拆解维度详解.md`（含完整拆解项清单、频道分流模板、手法标注词表）。

### 4.1 三维度与评分锚点

| 维度 | 拆什么 |
|------|--------|
| **市场** | 一句话卖点 / 读者画像 / 平台适配 / 竞争差异化 / 书名简介包装（D0-D1 补：数据表现） |
| **文本** | 开篇钩子（前300字出冲突/前500字亮金手指/前1000字出小爽点）/ 章末钩子四分类（危机·悬念·信息差·情绪）/ 对话占比 / 句式节奏 / 感官密度 / 对话风格 |
| **结构** | 剧情段切分 / 节奏（3章一小爽·10章一大爽）/ 伏笔埋设与回收 / 角色功能位映射 / 金手指绑定与成长阶梯 / 信息释放节奏 |

各维度 1-10 评分锚点见 `references/拆解维度详解.md` §1.6 / §2.7 / §3.6，评分必须对照锚点给出。

**评分纪律**：
- 量化数据优先用 `scripts/text_stats.py` 统计（见 4.4），无脚本结果时标注"估算"；
- 每个评分必须在报告里给出**扣分/得分的具体证据**（哪章哪里好/差），不允许裸分。

### 4.2 证据 Gate（防幻觉，全程强制）

**每一条拆解结论，必须二选一：**
- 附原文证据：`出处（第X章）+ 原文摘录（≤50字，保持原样）`；
- 或标注 `【推测】`并写明推断依据（如"由简介与评论推断"）。

**禁止**：编造统计数字（"平均句长14字"必须有脚本或抽样统计支撑）、引用不存在的章节内容、复述未经确认的情节。

### 4.3 拆解粒度：剧情段优先，章节为辅

按**剧情段**（一个完整事件单元）切分，不按章机械切：
- 每个剧情段记录：起止章节 / 核心冲突 / 主角变化 / 结尾钩子 / 情绪功能（铺垫·蓄力·爆发·余波）；
- 一章横跨两个剧情段时拆开记录；
- 逐章摘要仅对前 3 章和关键章节生成，其余以剧情段摘要覆盖。

### 4.4 文本统计（量化承诺的兑现）

优先运行脚本（纯 Python 标准库，无第三方依赖）：

```
python "<本技能目录>/scripts/text_stats.py" "拆文库/{书名}/原文"
```

输出：每章字数 / 段落数 / 段均字数 / 平均句长 / 短句占比 / 对话占比（段落+字数双口径）/ 标点频率（！？……——），汇总行含整体平均句长与整体短句占比。结果写入 `拆文库/{书名}/文风统计.md`。

**降级**（脚本不可用时）：抽样统计法——取前 3 章，每章手动统计：总字数、对话行数/总行数、句号数（≈句数）、感叹号省略号数量；报告标注"抽样估算"。

## Step 5：精彩片段库提取（核心产出）

> 这是拆文最直接的资产：**原句 + 它为什么好 + 你怎么用**。用户要"写作手法、精彩片段"，就落在这里。

存入 `拆文库/{书名}/片段库/`，四类分文件：

| 文件 | 收什么 | 每条必含 |
|------|--------|---------|
| `金句_对白.md` | 高辨识度对白（人物声口范本、潜台词、反差萌） | 原文摘录 + 出处章 + 手法标注 + 迁移提示 |
| `金句_叙述.md` | 叙述文笔亮点（比喻/白描/通感/长短句节奏/留白） | 同上 |
| `桥段_可复用.md` | 可换皮复用的情节桥段（打脸/误会/身份揭示/反转） | 原文摘录 + 桥段结构拆解（触发→铺垫→反转→收尾）+ 换皮方向 |
| `名场面.md` | 高潮场景完整拆解 | 原文摘录（可长）+ 节奏标注（铺垫→蓄力→爆发→余波四段的字数配比）+ 手法标注 |

条目格式见 `references/输出模板.md` §2。

**收录纪律**：
- 原文摘录**逐字保持原样**（这是后续文风对齐的基准语料，改动即失真）；
- 每类 3-15 条；素材不足时允许少于 3 条并在报告注明，**禁止为凑数收录平庸片段**；
- 手法标注从 `references/拆解维度详解.md` §5 手法词表中选取，不自造词；
- 产出后抽查校验：随机抽 5 条摘录，用文本检索（rg/grep）与 `原文/` 逐字比对，不一致即修正；
- **抄袭红线**：换皮只迁移**结构与情绪功能**；人名/地名/专有设定/连续字句与对标原文必须零重合，迁移产出按"连续 13 字重合"自查，命中即重写。

## Step 6：综合报告 + 可复用清单 + 质量自检

### 6.1 产出 `拆文报告.md`

结构（模板见 references/输出模板.md）：快照信息（日期/D级/置信度）→ 三维度评分表（带证据）→ 一句话总评 → 可复用清单。

### 6.2 质量自检（产出前必过，任一不过则返工）

- [ ] 报告头部有快照信息（日期/D级/置信度）
- [ ] 三维度每条结论都有原文证据或【推测】标注
- [ ] 量化数字有脚本/抽样支撑，或标注"估算"
- [ ] 片段库四文件齐全，每条含原文+手法+迁移提示
- [ ] D2/D3 数据没有产出文本/结构维度结论
- [ ] 评分都附了具体证据，无裸分

---

## Step 7：横向对比（拆 ≥2 本时执行）

产出 `拆文库/横向对比.md`：
- **共同点** = 品类标配（缺了就是残次品，列成 checklist）
- **差异点** = 差异化机会（各自的长板是什么，选一个方向深挖）
- **同位置不同处理** = 自由度证明（两本书在同一结构位置用了不同写法 → 该位置可以自由发挥）

## 输出目录结构

```
拆文库/
├── 选题决策.md                  ← Step 1 产出（扫榜选书时）
├── 横向对比.md                  ← Step 7 产出（多本时）
└── {书名}/
    ├── 原文/                    ← 用户提供，证据唯一来源
    │   └── 第NNN章_章名.md
    ├── 片段库/
    │   ├── 金句_对白.md
    │   ├── 金句_叙述.md
    │   ├── 桥段_可复用.md
    │   └── 名场面.md
    ├── 拆文报告.md              ← 综合报告（含三维度评分+可复用清单）
    ├── 文风统计.md              ← text_stats.py 输出（或抽样估算）
    ├── 剧情/
    │   ├── 剧情段拆解.md        ← 按剧情段切分的结构拆解
    │   └── 节奏与伏笔.md        ← 爽点分布/伏笔埋收清单
    └── 角色/
        └── {角色名}.md          ← 含功能位映射
```

> 下游写作技能需要引用拆文产出时，从 `拆文库/{书名}/` 按需读取即可。
