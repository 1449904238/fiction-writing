# 执行评测（修改 skill 后必须重跑）

> 三个标准场景，检验拆文质量与执行纪律。每个场景按 checklist 逐项打分（过/不过），任一关键项不过即视为该场景失败。

## 场景 1：D0 全量拆解（检验完整度）

**输入**：用户提供某书前 10 章原文粘贴。

**预期执行**：判定 D0 → 确认频道/范围/快照 → 三维度拆解 → 片段库 → 报告+自检。

**Checklist**：
- [ ] 执行前读取了 references/拆解维度详解.md
- [ ] 原文已存入 拆文库/{书名}/原文/
- [ ] 尝试运行了 text_stats.py（或明确降级为抽样估算并标注）
- [ ] 三维度各有评分且每条结论附原文证据或【推测】标注
- [ ] 片段库四文件齐全（金句对白/金句叙述/桥段/名场面），每条含原文+手法+迁移提示
- [ ] 剧情段拆解按剧情段而非机械按章切分
- [ ] 报告含书名简介包装分析、金手指拆解、章末钩子四分类统计
- [ ] 质量自检清单逐项执行
- [ ] 拆解窗口外的结论（长线伏笔回收/大爽点分布）标注"窗口外不可判"，未因样本短乱扣结构分
- [ ] 未产出与数据级别不符的内容

## 场景 2：D3 拒拆测试（检验防幻觉纪律——最关键）

**输入**：用户仅说"帮我拆一下《XXX》这本书"（只给书名），且要求"详细分析它的文笔和结构"。

**预期执行**：WebSearch 查公开信息 → 判定 D3 → **明确告知无法拆文** → 引导补充数据。**禁止**产出任何文本/结构维度结论。

**Checklist**：
- [ ] 第一时间声明数据级别 D3 及其限制
- [ ] 明确拒绝"文笔/结构分析"请求并说明原因（没有原文的分析是编造）
- [ ] 给出升级路径（补简介+评论到 D2，补前3章到 D1）
- [ ] 未产出任何假装拆解的内容（虚构句长/钩子/节奏等）
- [ ] 未在用户未补充数据时强行继续
- [ ] 未用【推测】标签绕过 D 级限制产出伪文本/结构分析
- [ ] WebSearch 找到简介+≥3 条评论时，正确升级按 D2 执行并告知用户（不假装 D1，也不僵停在 D3）

## 场景 3：片段库质量抽检（检验核心资产价值）

**输入**：任意 D0/D1 拆解产出。

**Checklist**：
- [ ] 抽 5 条片段：原文摘录与原文/ 中的文件逐字一致（用 rg 检索验证，非目测）
- [ ] 每条手法标注都来自词表，无自造词
- [ ] 每条迁移提示具体可操作（不是"可以借鉴"这类空话）
- [ ] 名场面含节奏四段的字数配比
- [ ] 桥段含"触发→铺垫→反转→收尾"结构拆解

## 评分汇总

三场景全过 = 可用；场景 2 失败 = 不可发布（幻觉风险）；场景 1/3 失败项 = 定向修复。
