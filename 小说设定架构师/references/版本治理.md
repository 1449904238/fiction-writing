# 版本治理

版本只表达一种状态，避免把技能、契约、单本设定和参考资料混在一起。

| 标识 | 所在位置 | 含义 | 修改时机 |
| --- | --- | --- | --- |
| `contract_version` | 三个 JSON 资产 | 机器接口版本，目前为 `1.0` | 增删/改名必填字段，或改变字段语义时升级 |
| `source_revision` | 三个 JSON 资产 | 某一本书的设定修订号，使用 `vMAJOR.MINOR.PATCH` | 设定内容、约束或引用改变时同步修改 |
| 参考资料日期/历史版本 | `references/` 文件正文 | 资料来源的维护记录，不是当前技能版本 | 仅在资料本身更新时修改 |

技能 `SKILL.md` 不再写 `version`、`V3.x`、`V5.x` 等运行时版本号。旧参考资料中的版本标题是来源记录，不能作为当前规则；若历史说明与本契约冲突，以本契约和题材模块为准。`manifest.json` 的 `source_revision` 是下游判断资产是否需要重新读取的唯一信号。

升级操作：先更新契约/参考文件，再更新 `contract_version`（如有必要），最后用新契约重新导出整套设定包。禁止只改一个 JSON 文件，禁止把迁移说明塞进小说简报。
