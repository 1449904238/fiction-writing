# 细纲扩写执行系统（独立版 · V5.1.0）

> **独立声明**：本 skill **永远单独使用**，不与其他任何 skill 产生关联，不依赖任何流水线。输入仅为**细纲文件**（格式参考 `示例_细纲产出/`：人读 `卷V-01_细纲与衔接.md` + 机读 `卷V-01_delta.json`），输出为**小说正文初稿**。

> **唯一外部配合**：学习资料知识库（外部 Obsidian）——扩写前按细纲标注的"主导情节类型"（plotNN）读取知识卡片（见「情节类型卡消费」）。不可读时不阻断。
>
> **质检职责边界**：本 skill 只负责"写出初稿"。产出后是否需要质检、如何质检**不由本 skill 决定**——需要时用户自行调用质检类 skill 在新对话执行。本 skill 内的 P0 预检/脱水自检/机检脚本属于"写作规则内嵌"，不替代独立质检。
>
> **版本**：V5.1.0 | **最后更新**：2026-08-30 | **V5.1.0 变更**：执行率升级——①新增 3 个机检脚本（check-ai-patterns 六项AI味检测 / check-output-structure 输出结构校验 / check-anchor-consistency 数值锚点一致性），终检第0步由单脚本升级为 4 脚本齐跑；②体量压缩（~20.9K→~14K tokens），规则速查卡化；③规则加 HARD(机检,必须)/SOFT(引导,允许偏差) 徽标；④场景驱动 Read 升级为"写前必须 Read"，输出加"已加载素材清单"；⑤新增场景间检查点（每2-3场景核对蓝图）与中途字数检查；⑥新增 /mode_check；⑦输入降级声明标准化 | **V5.0.0 变更**：独立化改造（详见 .workbuddy/backups 或旧版记录）

### 场景级蓝图生成（写前必做）

> 将章节分解为 3-5 个场景，分配字数预算与情节点，防止节奏靠"感觉"。

**蓝图结构**：每场景标注 场景类型 core(1200-1800)/important(800-1200)/transitional(400-800)/accent(200-400) + 字数预算 + 情节点(1-2个) + 感官策略 + 情绪节点(起→终) + 钩子(章末场景才有章末钩子)。预算总和=本章目标字数(±200)。

**蓝图规则**：
1. 按场景顺序逐一展开，不可跳过
2. 每场景字数不超预算±200
3. 场景类型决定感官密度（过渡场景禁五感叠加）
4. 情绪节点前后衔接（A场景终点=B场景起点）
5. 章末场景必须有章末钩子（钩子类型多样，配合"章末收尾轮换清单"轮换，3章内不重复）
6. **场景间检查点（D1）**：每写完 2-3 个场景，暂停对照蓝图核对 ①累计字数 vs 预算 ②本场景情绪终点是否为下场景起点 ③感官策略是否按表投放。偏离>±200 立即调整，防整章跑偏返工

**蓝图与细纲关系**：蓝图是细纲的"执行级细化"——细纲管"写什么"，蓝图管"怎么写"。

### 场景感官策略标准模板（场景类型×感官组合决策表）

> 与 `references/感官细节库.md` 协同：本表管"选哪些感官"，感官库管"用什么词"。●●=重点(具体感官词)/●=必要(1-2句)/○=可选

| 场景类型 | 字数 | 视觉 | 听觉 | 触觉 | 嗅觉 | 味觉 | 组合策略 |
|---------|------|------|------|------|------|------|---------|
| core | 1200-1800 | ●● | ●● | ● | ○ | ○ | 视听触叠加，关键节点加嗅觉点睛；味觉仅限口腔受伤/中毒 |
| important | 800-1200 | ●● | ● | ○ | ○ | ○ | 视觉为主+听觉辅助；触觉仅限直接接触；嗅觉味觉禁用 |
| transitional | 400-800 | ● | ○ | ○ | ○ | ○ | 单一视觉快进，1个精准细节锚定；其余感官禁用 |
| accent | 200-400 | ● | ○ | ○ | ○ | ○ | 单一感官点睛，1句1词收束；禁止叠加 |

**禁忌**：①transitional 禁五感全开（"闻到桂花香，听见鸟叫，感到微风…"=伪细腻，改单一视觉）；②accent 禁叠加（"铜钱冰凉，带着铁锈味"→"铜钱棱角硌进肉里"）；③core 禁纯视觉（须有身体在场感：触觉/听觉）；④相邻场景感官词不重复（查感官库换词）。

**示例**：core="警报灯刷红走廊(视觉)+震动传膝盖(触觉)+警报切割空气(听觉)+焦糊味(嗅觉点睛)"；important="竹简堆到天花板(视觉)+笔尖刮竹面沙沙(听觉)"；transitional="穿过前厅绕过影壁，廊下灯笼透出昏黄光晕"；accent="铜钱棱角硌进肉里"。

### 扩写前置上下文强耦合协议（五维一体加载）

扩写前必须在内存中对齐五个维度，否则不准动笔：

```
【维度1：单章情节血肉（来自输入细纲）】 本章主要冲突、台词路线、衔接包
【维度2：宏观情绪阀门（来自细纲章节定位）】 情感温度（🔥大爆发/🌡️蓄力过渡/❄️压抑铺垫）
  └─ 蓄力/铺垫章→压制文字张力，禁高光打斗和顶级怼人话术
【维度3：下文钩子倒逼（来自细纲多线/伏笔）】 下一章爽点？本章哪些细节为下一章服务？
  └─ 本章绝对禁止提前释放下一章爽感
【维度4：情绪工程锚点（来自细纲情绪蓝图）】 目标情绪[爽/虐/燃/酸/惧/暖]+曲线+锚点+通路[A压抑爆发/B五感榨汁/C配角杠杆]

【维度5：网感场景标记（来自细纲章节意图）】 net_slang_scene = true/false
  └─ true→对话/内心可用网络梗（references/网络梗素材库.md）；false→不主动用；禁止进叙述者总结层
```

## 规则分层体系

### 优先级徽标（B3）

- **[HARD]** = 机械可检查（多为机检脚本覆盖），违反=必须改，无例外
- **[SOFT]** = 引导性技法，允许合理偏差，写前先保 HARD

### 质感注入协议速查（HARD 技法4/5，SOFT 其余 · 完整版 references/03_质感注入协议.md）

1. **[HARD] 动作链写生理状态**：不写"他很饿"，写3-4个连续动作。"他撕下半块饼，先闻了闻，再塞进嘴里慢慢含化"。单个无意义触碰=删除
2. **[HARD] 具体名词替代抽象形容词**："很旧"→"门轴上的锈已经爬满了合页"
3. **[HARD] 设定藏在生活里**：不写设定文档，写分配制度/交易场景/生活习惯。"天光石按户分配，每户每天拳头大的一块"
4. **[HARD] 感官精准投放**：日常过渡1个精准细节，核心场景3-5感官（按感官决策表）
5. **[SOFT] 对话要有人味**：口癖/跑题/言不由衷/信息差

### 情绪工程协议速查（HARD Layer2 · 完整版 references/03_情绪工程协议.md）

- **Layer1 情绪蓝图**（细纲层）：目标情绪+曲线+公式检验
- **Layer2 情绪锚点**（扩写层）：[HARD] 至少1个"小而具体+角色独有+日常受阻+不解释"的物理物件/动作
- **Layer3 情绪通路**（扩写层）：A压抑→爆发反差 / B五感榨汁机 / C配角杠杆

### 最高优先级铁律：反注水与白噪音绝对禁区（HARD）

> ⚠️ 优先级高于下方所有规则。触发任何一条=严重违规，必须立即修正。

```
1. 禁止"循环式排查"：相似物品禁超过1次重复描写，用"一路看过去"概括。
   ❌"第一只展柜""第二只展柜""第三只展柜" ✅"他一路看过去，维护记录都差不多。"
2. 禁止"无意义物理触碰反馈"：普通物品触感/磨损声/笔帽咔哒=删除。
   ❌"他把笔帽拔下来，又按回去，发出轻微的咔哒声。" ✅"他接过笔，签了名。"
3. 禁止"滥用感官比喻"：日常场景禁"像从地底深处""沉积了千百年"等文艺修辞。
   ❌"像有人从地底深处抽出一口沉积了千百年的空气。" ✅"空调开得很足，屋里凉。"
4. 禁止"心理活动套娃"：禁"他原本预期是...但他发现..."废话句式；禁对日常事物哲学思辨。
   ❌"遗忘是冷的。比十八度的空调更冷。" ✅"他没再想。关了灯。"
5. 禁止"潜台词解释"：永远不替读者总结。禁"他发现…/这说明…/这意味着…/他在等…"、心理实况转播。
   【绝对违禁词库】叙述语严禁：觉得/知道/意味着/是因为/看出规律/异乎寻常/看来/他发现/这说明/他心里明白/他在等/他意识到/显然/可见 → 替换为客观物证
   【AI画面腔违禁词库】叙述语严禁：眼中闪过一丝/嘴角微微上扬/空气中弥漫着/不禁/不得不说/仿佛在诉说着/交织(情绪类)/洗礼/在这一刻(时间仿佛静止)
   【推理留白】角色发现秘密→只写"客观物证"，不写结论。
   ❌"这个温度是给展品定的，展品怕热。" ✅"温控表指针钉在十八度。白术吐出一口白气。"
6. 禁止"弱智明喻"（戒断"像"字）：悬疑感来源于不合理的客观事实。
   【比喻质量门】三重门（精准/记忆/不可替代）密度≤3次/千字；≥4次/千字=机检 blocking（check-ai-patterns.js）
   ├─ 精准门：喻体是能立即感官联想的具体物（✅"胃里像有只手在拧" ❌"像沉积了千百年的空气"）
   ├─ 记忆门：创造画面记忆点，非填充间隙
   └─ 不可替代门：删掉换成直白描写效果一样好？→删
   对话中的比喻不受限制。
   【句法代偿】想用"A像B"→物理痕迹法（写A本身的材质/损耗/数据）或生理反馈法（身体直接承受）
```

### 跨章去重协议（HARD · 脚本驱动）

> 扩写前跑 `node scripts/extract-used-patterns.js --json <最近N章>` 提取 used_patterns；缺失时①优先从近3章正文提取②不可获取→标注"[跨章去重降级]"跳过③不得停生成。

1. **句式去重**：已用模板骨架（固定骨架只换关键词的句式），下2章内不得再用
2. **设定解释去重**：已完整解释的设定，后续不同句式简短带过或省略
3. **场景元素去重**：同类场景（救人/战斗/对峙/探索/日常）近5章内须差异化≥3维度（外观/生理反应/环境细节/台词/动作），≤1维度=重写
4. **输出**：定位报告附"本章已用模板句式清单"+"本章场景元素清单"，供下一章喂入

### 章末收尾轮换清单（HARD）

> 5种收尾方式强制轮换，同一种不能连续用于相邻两章。扩写前从衔接包获取上一章收尾编号，本章换一种；未指定→默认①→③→②→⑤→④。禁止排比句、抒情句、省略号悬念。

```
① 动作悬停："他摸出钥匙，插进锁孔，没转。"
② 对话钩子："'你认错人了。'她说。"
③ 环境意象收束："走廊尽头的声控灯熄了。黑暗里只剩水磨石地面泛着一点冷光。"
④ 内心独白留白："他想，明天得早点来。"
⑤ 信息差悬念："他不知道，三楼那盏灯又亮了。"
```

### 绝对铁律（Top 5 · HARD — 违反即重写）

```
【铁律1】衔接包"禁止矛盾"清单是最高优先级，任何情况下不得违反。
【铁律2】字数必须3500-4500字（区间服从细纲字数目标，默认3500-4500）。出稿前跑 `node scripts/check-wordcount.js <正文>`，以脚本计数为准。字数<90%→禁止整体注水，按场景蓝图预算定位欠账（密点被写成带过→一次性重写到预算，疏点保持简短）；>110%→压过场、合并疏点、删过渡。
  【D2 中途字数检查】扩写约50%时跑一次 `node scripts/check-wordcount.js --narrative-only <正文>`，早发现早调整，避免整章返工。
【铁律3】故事必须推进。每个场景至少推进1条信息线（剧情/人设/世界观/关系）。全文无推进=重写。
【铁律4】情绪词配额制（三级强度，HARD）：
  L1 transitional/accent=0个，纯Show | L2 important≤1个/场景 | L3 core≤2个/千字；每章总量≤5个。
  情绪词指"悲伤/痛苦/绝望/愤怒/狂喜/恐惧"等直接命名情绪的形容词/状态词。违反配额→重写。
  ✅L3"他猛地砸下拳头，愤怒像烧红的铁块堵在胸口。" ✅L2"他攥紧杯子，指节发白。心底漫上一阵钝痛。" ✅L1"他试图把碎掉的杯子拼起来，拼了五分钟。"
【铁律5】喜剧反差法则：写笑点时角色绝对严肃。禁"滑稽/可笑/搞笑/忍俊不禁"。
  用最正经的语调写最离谱的行为。✅"他站得笔直，脸上没有一丝表情。裤腿上的泥巴还在往下掉。"
```

### 弹性建议（SOFT — 建议遵守，允许合理突破）

```
【建议1】对话避免连续4句纯对话无打断。允许突破：快速交锋/电话/压迫感对话。
【建议2】感官精准投放：日常背景1个精准细节锚定；核心异常点多维叠加；主角务实冷静，反馈基于生存压力（工资/房租），禁哲学思辨。
【建议3】句式节奏服从文风。连续1500字无长句碎步，或单段超400字无断句→调整。
【建议4】摄影机焦距：远景快进（赶路/等待）禁微动作/感官/心理，15字内闪回；中景叙事每300字最多1处微动作；特写高光仅限8大事件（生死绝境/境界突破/重大打脸/首登场等）。非冲突期禁视线轨迹（"目光扫过"）、情绪垫字（"他愣了一下"）。
【建议5】排版：不影响后续剧情的动作20字内结束；平均每段≤80字，>150字自然段打碎；章尾禁排比/抒情/省略号悬念，干净动作收尾。
【建议6】章首300字动态进入（番茄黄金三章）：前300字内进入冲突/异常/行动/对话交锋，静态铺陈≤300字（全书首章例外500字）。环境信息拆进动作对话释放。
【建议7·风格可选项】脏感注入深度由题材决定；闲笔率高潮章5-10%/过渡自然；成语/俗语/歇后语优先角色台词，禁段落末尾总结性堆砌（❌"这一战，真是惊天动地、气壮山河。"）
```
