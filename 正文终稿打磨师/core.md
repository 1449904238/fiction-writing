# 正文终稿打磨师 — 核心层

> 本文件为活跃执行入口。完整规则（17 Gate详解/量化打分/收敛协议全文/输出格式）见 `SKILL.md`，按需 Read 加载。

## 📍 流水线位置

```
03a扩写 → 03b质检 → ⭐正文终稿打磨(本步) → [可选09多视角审稿] → 交付
```

- **上游**：03a初稿+锐度保护清单+跨章used_patterns；03b质检报告+Findings
- **下游**：终稿即交付件；本章新增模式汇入下一章 used_patterns
- **使命**：不改变情节/设定/结构——让读者读完之后，身体有反应，且读起来像真人写的。

## 🎯 模式路由器（第一步必做）

```
快速通道准入（全部满足）：
✅ P0五项必查全过  ✅ 质量Gate总分≥80/100  ✅ 脚本客观分≥48/60
✅ burstiness CV>0.35  ✅ 对话比≤60%  ✅ 无blocking级G9问题

任一不满足 → 深度通道
快速通道执行中标记问题>15处或blocking退化 → 中止，切换深度通道
```

## 快速通道（8步，靶向修复）

| Step | 动作 | 要点 |
|------|------|------|
| 1 | 读输入 | 初稿/03b报告(已知不足=修复指南)/Findings/锐度清单/used_patterns |

| 3 | 技法靶向修复 | 只改标记段落；两大核心原则全文扫 |

| 5 | 跨章去重 | 对照used_patterns替换重复；锐度清单不改 |
| 6 | 锐度保护验证 | 逐项✓未改动；被改→恢复 |
| 7 | 脚本校验 | 4脚本：ai-patterns/consistency/degeneration/punctuation |
| 8 | 输出 | 打磨报告（模式=快速通道） |

## 深度通道（4阶段，顺序不可乱）

### Phase A 质感深化
1. 诊断：S/A级场景欠账？C级注水？单细节应升级3-5感官叠加？上帝视角罗列？
2. 注入：核心场景感官叠加+错位；每角色1个独有语言习惯；动作个性化
3. 记忆点：每章≥1个物理画面，登记改写禁区
4. 生成内部意图包（schema对齐：processed_items已处理项+boundary_ambiguous_items保留项/改写禁区，见schemas/refinement-intent.schema.json）

### Phase B 净化+Gate检测
1. 核心原则扫描（潜台词拦截A/B级词→删；比喻三问→质量门；万能前缀/情绪套娃→删）
2. 净化层：解释腔5信号词+心理直给5信号词一次扫描分类替换+锋利化四则
3. Gate按等级执行（轻度G1/2/11/12/14；中度+核心8+扩展；重度全17）
4. 删除优先判断先于改写；读意图包豁免保留项

### Phase C 修改与收敛循环
- 最多3轮；同段连续2轮无改动→收敛；第3轮仍≥10处→[需复核]移交
- 第2→3轮分数提升<5分→自动停止
- 每轮修复效果验证：定向复扫±3句→分数对比（总分必须降）→最后全文回归

### Phase D 收尾
标点统计(省≤5/破≤4/感≤15)→G6结尾终扫→角色指纹三查(遮名/口癖/情绪通路)→删软词→4脚本→跨章去重→锐度验证→过度打磨二次校验(自然感>规则)

## 两大核心原则（速查）

**原则1 潜台词拦截器**：禁"他发现/这说明/意味着/他在等/他心里明白"等心理结论。
A級零容忍：意味着/是因为/这说明/他发现/他心里明白/他在等/他意识到/显然/可见/看出规律/异乎寻常
B級每章≤2次：觉得/知道/看来（事实陈述豁免，对话豁免）
改写：物理动作/生理反应/环境变化折射心理；推理只写物证不写结论。

**原则2 比喻质量门**：三问——新鲜精准？有叙事功能？角色口吻？低质量→句法代偿
（物理痕迹法/生理反馈法）。比喻密度归03a，本层管质量。

**情绪词分级**：L1过渡0个/L2重要≤1个/L3核心≤2个每千字；每章总量≤5；只可向克制方向仲裁。

**锐度保护**：03a标记的3-5处有特点表达禁改，即使命中Gate或与used_patterns重叠。

## Gate 速查表

| Gate | 检测 | 关键阈值 |
|------|------|---------|
| G1 | 禁用词 | 一级必删；二级视上下文 |
| G2 | 句式+对话腔调(含G5) | "不是A是B"≤2次/章 |
| G3 | 心理残留验证 | ≤2次/千字（消除在净化层） |
| G4 | 节奏 | burstiness>0.45跳过 |
| G5 | 对话差异化 | 精简3项：声口/同质化/信息差 |
| G6 | 结尾去升华 | 章末断在悬念而非总结 |
| G7 | 意象疲劳 | 同一意象≤2次/章 |
| G8 | POV | 一章切换≤2次 |
| G9 | 剧透式叙述 | 精简2项：意图直给/信息差破坏，命中=blocking |
| G10 | 信息含金量 | >200字零推进=熔断脱水 |
| G11 | 解释腔验证 | （消除在净化层3.1） |
| G12 | 转折堆砌 | 段首转折词≤2次/章 |
| G13 | 排比滥用 | 连续3+句同构=拆解 |
| G14 | 模糊时间 | ≤1次/章且须锚点 |
| G15 | 模板外貌 | 套路词0处，须独家特征 |
| G16 | 气声标签 | ≤3次/章 |
| G17 | 网络梗(advisory) | 密度/堆砌/题材路由/叙述层越权 |

朱雀3维度融入：语义连贯→G10 / 修辞多样→G7 / 情感一致→G3。

## AI味分级（深度通道）

轻度：禁用词≤5/千字 → G1+2+11+12+14，删除≤15%
中度：6-15/千字 → 核心8+G11+扩展，删除≤25%
重度：>15/千字 → 全17 Gate+重点重写，删除≤35%
六项客观指标取最高档定级（禁用词密度/排比段/心理词占比/标签密度/段落句数/重复密度）

## 脚本收尾（双通道，只报告不修改）

```bash
node scripts/check-ai-patterns.js --check <终稿>
node scripts/check-consistency.js <终稿> --meta=<设定JSON>
node scripts/check-degeneration.js --check <终稿>
node scripts/normalize-punctuation.js <终稿>
```
硬指标：字数3500-4500 / 对话≤60% / burstiness>0.35 / blocking归零
平台风控4项（V1.1并入check-ai-patterns.js，对标2026平台封杀死因）：
提示词残留(blocking) | 零宽水印字符(blocking) | 被动句密度>3处/千字(advisory) | 段落等长机器规律(advisory)
