# 内化质检协议（进稿质检 + 评分分流）

> 版本：V1.0 | 归属：正文终稿打磨师（本技能内置，不依赖任何外部质检技能）
> 来源：内化自原「03b 质量自检」的 P0/P1 检查项 + V5.3.1 混合评分模型 + Findings 格式，已去除外部技能依赖，由本技能主线程直接执行。
> 背景：原 03b 质量自检技能已移除，本协议替代其职责——对进稿正文完成**零容忍检查 + 质量评分 + 通道分流**，保证打磨流程的准入判断自包含。
> 脚本依赖：`scripts/check-quality-score.js`（已内化，`./lib/prose-utils.js` 与既有脚本共用，不依赖外部 npm 包）。

---

## 一、进稿质检流程（每章必做，保持执行率）

收到正文初稿后，**先执行内置质检，再进入打磨通道**：

1. **P0 零容忍检查**（人工/LLM 执行，4 项全过才准入，任一不过先退回修正）：
   - 常识性错误：物理/时间线/因果/知识性硬伤（如"白天突然变黑夜""角色已死又说话"）
   - 语句可读性：语序错乱、成分残缺、标点误用导致无法通读的句子
   - 禁用词/AI 味 blocking：提示词残留、零宽水印、直接情绪词滥用（脚本 `check-ai-patterns.js` + `check-quality-score.js` 的 AI 味基线辅助）
   - 情节一致性：与衔接包[禁止矛盾]/[状态锁定]清单冲突（若有衔接包）

2. **质量评分**（V5.3.1 混合评分模型，100 分制）：
   - 脚本客观分（60 分）：运行 `node scripts/check-quality-score.js --file=<正文> [--handoff=<衔接包JSON>] [--metadata=<设定JSON>]`，含 5 个客观维度：
     - 情节推进力（15 分）：信息密度检测，每 500 字分段计算
     - 节奏控制（15 分）：burstiness CV≥0.5 满分，<0.3 得 0 分
     - 质感密度（10 分）：感官词频 + 比喻密度≤3 次/千字
     - 角色一致性（10 分）：名称/数值/知识边界矛盾检测
     - AI 味基线（10 分）：blocking 级问题计数（0 个=10 分）
   - LLM 主观分（40 分，不压缩）：
     - 情绪到达率（20 分）：20=读者生理性紧张 / 15=能感知情绪 / 10=可理解但平淡 / 0=无情绪传递
     - 角色辨识度（20 分）：遮名测试；20=遮名可辨 / 15=有口癖 / 10=区分度弱 / 0=说话全一样
   - 总分 = 客观分 + 主观分（最高 100 分）

3. **通道分流**（与评分对应）：
   | 评分区间 | 通道 | 本技能执行 |
   |---|---|---|
   | ≥80 分 | 快速通道 | 靶向修复（见快速通道工作流） |
   | 60-79 分 | 深度通道 | 质感深化三步法 + 17 Gate + 收敛循环 |
   | <60 分 | 返工 | 退回上游重写，重新进稿质检 |

4. **Findings 输出**（与既有 findings 体系对齐，供本技能报告引用）：
   ```json
   {
     "severity": "blocking|major|minor",
     "category": "一致性|常识|可读性|AI味|节奏|其他",
     "location": "章节/段落/行号",
     "evidence": "原文摘录",
     "issue": "问题描述",
     "fix": "修复建议"
   }
   ```

## 二、兼容策略（存量项目）

- **已有 03b 质检报告**（旧项目遗留）：直接采用其评分与 Findings，跳过内置质检第 1-2 步（等价于原流程），仅在报告缺失或明显过期时执行内置质检。
- **无外部报告**（常态）：按本协议执行完整内置质检。

---

## 三、与 Gate 体系的边界

- 内置质检负责**进稿准入**（P0 零容忍 + 评分分流 + Findings 靶向定位），替代原 03b 职责。
- 17 Gate 负责**打磨过程检测**（逐 Gate 精修质检），职责不变。
- 章内意象重复等原"03a/03b 初检"项：由内置质检的 P0 情节一致性 + 快速/深度通道中的跨章去重（check-consistency.js）覆盖，Gate 终检复查逻辑不变。
- 原"每 3 章触发外部审稿"机制不再存在——周期性深度审稿由本技能**独立终检**（见 `references/独立终检协议.md`，卷末/质量存疑时触发）承接，趋势性检查建议每 5 章做一次 lean 级自查（可直接复用本协议评分对比）。
